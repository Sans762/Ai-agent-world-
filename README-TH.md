# NAMO AGENT WORLD — UNIFIED CLOUD v0.2

**โปรเจกต์เดียว / หน้าเว็บเดียว / ฐานข้อมูลกลางเดียว / ลิงก์เดียว** รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์ ไม่ต้องติดตั้งแอปแยกเครื่อง ไม่ใช้ Remote Desktop Commander และไม่แตะโปรเจกต์ AI เดิมบนคอม

## สิ่งที่มีอยู่ในโปรเจกต์นี้

- `public/` — เกมเมืองพิกเซลมุมมองบนแบบ 16-bit, อาคาร 12 หลัง ภายในห้อง โต๊ะ คอม เก้าอี้ ทางเดิน ต้นไม้ ตัวละคร Agent หกบทบาท แผนที่ย่อ การซูม แตะและลากบนมือถือ
- `src/worker.js` — ระบบ API กลาง ใช้ Cloudflare Workers ร่วมกับหน้าเว็บ **ที่ URL เดียวกัน**
- `migrations/0001_tasks.sql` — ฐานข้อมูล D1 เดียวกันทุกอุปกรณ์
- ระบบงาน — สร้างงาน มอบหมายงาน บันทึกสถานะ รับผลลัพธ์ และดูงานล่าสุดจากอุปกรณ์อื่น (เมื่อเข้าสู่ระบบ Cloud ด้วย OWNER_KEY เดียวกัน)
- Gemini — ใช้ API ของ Gemini ผ่าน Worker Secret เพื่อทำงานจริงตามบทบาทหลังเชื่อมคีย์และโควตา Free Tier ยังใช้ได้ (โควตาอาจเปลี่ยนแปลง)
- ChatGPT และ Claude — เปิดเว็บไซต์และคัดลอกคำสั่งงาน พร้อม **นำคำตอบกลับมาบันทึกลงงานกลางได้** โดยระบุแหล่งที่มา ไม่ใช่ API อัตโนมัติและไม่ใช่การย้ายแชตเดิมเข้ามา

**Agent ที่เดินในเมืองเป็น visualization ของสถานะมอบหมาย/ทำงานที่ระบบรู้จัก ไม่ได้หมายความว่ามี AI 6 โมเดลทำงานอัตโนมัติพร้อมกัน**; การคิดจริงต้องใช้บริการที่เชื่อมไว้ และมีการอนุมัติ/สั่งแต่ละงาน

## ติดตั้งบน Cloudflare เพียงครั้งเดียว

Cloudflare Workers สามารถเผยแพร่ทั้งไฟล์เว็บไซต์และ Worker backend **ในการ deploy ครั้งเดียว** (Workers Static Assets) หลัง Deploy จะได้ลิงก์ `.workers.dev` เดียวและใช้งานบนมือถือหรือคอมก็เป็นเว็บเดียวกัน ไม่ต้องเปิดคอมไว้

1. สมัครหรือเข้าสู่ระบบ Cloudflare ที่ https://dash.cloudflare.com/ (Free plan รองรับการทดลอง มีโควตาจำกัด)
2. แตก ZIP นี้ลงใน GitHub Codespaces หรือสภาพแวดล้อมที่มี Node.js + npm (ใช้จากเบราว์เซอร์มือถือได้หากบัญชี GitHub ของคุณเปิด Codespaces)
3. จากโฟลเดอร์ที่มี `wrangler.toml` รัน:

```bash
bash scripts/deploy-one-app.sh
```

สคริปต์จะขอให้คุณล็อกอิน Cloudflare, สร้างฐานข้อมูล D1, ตั้งรหัส `OWNER_KEY`, เลือกเปิด Gemini และ Deploy **หนึ่งเว็บไซต์** เท่านั้น รหัสต่าง ๆ กรอกในหน้าหรือคำสั่งของ Cloudflare โดยตรง ห้ามส่งในแชตหรือใส่ลง GitHub

**หรือรันแยกเอง:**

```bash
npm install
npx wrangler login
npx wrangler d1 create namo-world-db --binding DB --update-config
npx wrangler d1 migrations apply namo-world-db --remote
npx wrangler secret put OWNER_KEY
# ถ้าต้องการเปิด Gemini:
npx wrangler secret put GEMINI_API_KEY
npx wrangler deploy
```

ถ้าเคยสร้าง D1 แล้วให้ใช้ binding เดิม อย่ารัน `d1 create` ซ้ำโดยไม่ตั้งใจ ชื่อ URL จริงขึ้นกับชื่อ Worker และบัญชี Cloudflare ของคุณ และจะไม่เปลี่ยนตามอุปกรณ์ที่เปิด

## เริ่มใช้งานบนมือถือและคอม

1. เปิด URL **อันเดียวกัน** ที่ได้จาก `wrangler deploy` ทั้งใน Chrome มือถือและบนคอม
2. เปิดแท็บ **ตั้งค่า** และกรอก `OWNER_KEY` ที่คุณตั้งใน Cloudflare — ใช้รหัส **เดียวกัน** ในทั้งสองเครื่อง (ต้องกรอกครั้งแรกในแต่ละเซสชัน)
3. สถานะมุมบนเปลี่ยนเป็น `SYNC` แสดงว่ากำลังอ่าน/บันทึกข้อมูลจาก D1 กลาง
4. เปิดแท็บ **งาน** สร้างงานแล้วมอบหมายให้ Agent — เปิด URL บนอุปกรณ์อื่นที่ล็อกอินไว้ จะเห็นงานเดียวกันภายในรอบซิงก์
5. เมื่อเปิด Gemini Secret แล้วสามารถสั่ง Gemini ทำงาน จากนั้นเปิดผลลัพธ์ที่บันทึกในงานนั้นได้
6. ถ้าอยากใช้ ChatGPT หรือ Claude โดยไม่จ่าย API ให้กด **ส่งไป ChatGPT/Claude** จากงานที่มอบหมาย ระบบจะคัดลอก Prompt ให้; หลังได้รับคำตอบกด **นำคำตอบกลับมา** เพื่อบันทึกผลลัพธ์เข้าสู่ D1 — เป็น **manual handoff** ไม่ใช่บริการ AI ที่ตอบในเว็บอัตโนมัติ

หาก Cloudflare มีฐานข้อมูลพร้อมแต่ยังไม่ได้เข้าระบบ แอปจะ **ไม่สร้างงานลง localStorage แยกเครื่องโดยไม่บอก**; ต้องเข้าสู่ระบบก่อนเพื่อให้งานตรงกัน ข้อมูลโหมดตัวอย่างเก่าที่เคยสร้างไว้ในเบราว์เซอร์ยังไม่ถูกย้ายอัตโนมัติ ให้ใช้ปุ่มส่งออกข้อมูลเก็บสำรองไว้ก่อน

## ขอบเขตและความปลอดภัย

- ไม่ต้องมีคอมเปิดอยู่สำหรับดูแผนที่และงาน Cloud หลัง deploy แต่ AI ที่รันในคอมของคุณ เช่น Codex CLI จะ **ไม่** เชื่อมเข้า Worker อัตโนมัติในขณะเครื่องปิด
- OpenAI/Claude แบบเว็บไม่สามารถใช้แทน API อัตโนมัติแบบฟรีไร้ข้อจำกัดได้; ระบบรุ่นนี้ใช้การคัดลอกและนำคำตอบกลับมาสำหรับสองบริการนี้
- Gemini ต้องใช้ `GEMINI_API_KEY` ของคุณเป็น Worker Secret และอยู่ในโควตาที่ Google กำหนด ไม่ใช่ฟรีไม่จำกัด
- API ข้อมูลต้องมี `OWNER_KEY` ที่ปลอดภัย (ขั้นต่ำ 12 ตัวอักษร); ยังไม่ใช่ระบบบัญชีหลายผู้ใช้หรือแอป production ที่ตรวจสอบความปลอดภัยครบถ้วน
- Cloudflare Free plan มีข้อจำกัดด้านคำขอและ D1; ไม่รับประกัน uptime หรือ AI ทำงานเบื้องหลังตลอด 24 ชั่วโมง
- ตอนนี้ยัง **ไม่ได้เผยแพร่ขึ้นบัญชี Cloudflare ของคุณจริง**: ต้องยืนยัน Cloudflare login และตั้ง Secrets ในบัญชีผู้ใช้จึงจะได้ URL ออนไลน์ที่เปิดจากทุกเครื่องได้
